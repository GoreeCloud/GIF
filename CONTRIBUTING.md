# Contributing

Use issues and short pull requests for changes. Keep app code, unit tests, media provenance, license notices and reproducible build workflows in this repository. Run `./gradlew :app:testDebugUnitTest :app:assembleDebug :app:lintDebug` before requesting review, and report what actually ran. No secrets or credential files may be committed. Third-party source/assets require license, dependency, safety and maintainer review before import. Native design must follow the current GoreeCloud UI authority; Android UI must remain within approved Compose/Kotlin framework rules.
